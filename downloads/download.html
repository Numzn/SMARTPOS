NUMZ POS for Windows

Desktop app, version 1.0.0 · Windows 10 / 11 (64-bit) · 108M

Download NUMZ-POS-Setup.exe

Install

  1. Run NUMZ-POS-Setup.exe and follow the installer.
  2. Open NUMZ POS from the desktop shortcut or Start menu.
  3. Sign in as usual. The app connects to pos.lab.numz.site automatically (you can change the server later under File → Server settings).
This build is not yet code-signed. Windows may show “Windows protected your PC”. Choose More info, then Run anyway, only if you downloaded this file from this page.
