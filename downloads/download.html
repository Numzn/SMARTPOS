NUMZ POS for Windows

Desktop app, version 1.0.0 · Windows 10 / 11 (64-bit) · 108M

Install

  1. Run NUMZ-POS-Setup.exe and follow the installer.
  2. Open NUMZ POS from the desktop shortcut or Start menu.
  3. When asked for the server address, enter https://pos.lab.numz.site, then sign in as usual.
